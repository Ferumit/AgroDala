# Макеты страниц

Вместо макетов в Figma — скриншоты свёрстанных страниц с тестовыми данными из базы. Снимает их
`npm run screenshots` в Chromium: компьютер — окно 1366×900, планшет — 768×1024, телефон — 390×844 и
360×640 (эмуляция Pixel 7).

Все страницы работают: каталог (фильтры, сортировка, поиск), вход и регистрация, корзина и
оформление заказа, личный кабинет, административная панель (товары, категории, заказы, импорт).
Фото товаров взяты с Wikimedia Commons, авторы перечислены в [image-credits.md](image-credits.md).

## Главная страница

Иконки категорий вверху страницы, под ними раскрывающийся блок фильтров и сортировки, ниже —
карточки товаров из базы.

![Главная страница, компьютер](screenshots/01-glavnaya-pk.png)

Блок фильтров раскрыт: назначение, тип, страна, ценовой диапазон или своя цена «от — до»,
производитель, наличие, сортировка. Выбраны «Для дачи и сада», «Китай», «Только в наличии» и
«Сначала дешёвые»: число подходящих товаров видно на кнопке ещё до применения.

![Фильтры и сортировка, компьютер](screenshots/02-filtry-pk.png)

После «Показать» — подборка из базы. Фильтры записаны в адрес страницы
(`index.html?purpose=garden&origin=china&stock=1&sort=priceAsc`), рядом с заголовком блока —
число выбранных фильтров.

![Подборка по фильтрам, компьютер](screenshots/24-podborka-pk.png)

Поиск из шапки: «лопаты» находит обе лопаты (окончание отбрасывается). Если ничего не нашлось —
сообщение и кнопка сброса.

![Поиск, компьютер](screenshots/25-poisk-pk.png)

![Ничего не найдено, компьютер](screenshots/26-nichego-pk.png)

Категория «Полив и опрыскивание» — открывается одним нажатием на иконку.

![Категория, компьютер](screenshots/03-kategoriya-pk.png)

На телефоне иконки категорий прокручиваются по горизонтали, товары идут в две колонки, на планшете —
в три.

## Корзина и оформление заказа

Корзина покупателя из базы: цены берутся из каталога, у товара без фото — иконка.

![Корзина, компьютер](screenshots/08-korzina-pk.png)

![Корзина, телефон](screenshots/12-korzina-telefon.png)

Полный сценарий покупки. Кнопка «В корзину» в карточке товара сразу показывает, сколько штук уже
в корзине:

![В корзину, компьютер](screenshots/30-v-korzinu-pk.png)

Оформление: имя, телефон и адрес подставлены из профиля, адрес нужен только для доставки. Итог на
странице — для покупателя; окончательную сумму считает Cloud Function `placeOrder` по ценам каталога.

![Оформление заказа, компьютер](screenshots/31-oformlenie-pk.png)

![Заказ оформлен, компьютер](screenshots/32-zakaz-oformlen-pk.png)

## Административная панель

Разделы зависят от роли: контент-менеджер не видит заказов, менеджер по продажам — импорта.

![Административная панель, компьютер](screenshots/11-admin-pk.png)

![Заказы, компьютер](screenshots/14-admin-zakazy-pk.png)

![Импорт, компьютер](screenshots/15-admin-import-pk.png)

![Заказы, телефон](screenshots/18-admin-telefon.png)

Менеджер открывает новый заказ и ведёт его по статусам: кнопки показывают только допустимые
переходы (самовывоз — «Готов к выдаче», доставка — «Передать в доставку»).

![Заказ в админ-панели, компьютер](screenshots/34-admin-zakaz-pk.png)

![Заказ подтверждён, компьютер](screenshots/35-admin-status-pk.png)

Контент-менеджер добавляет товар с фотографией (фото уменьшается в браузере и загружается в Cloud
Storage) и категорию.

![Новый товар, компьютер](screenshots/36-admin-tovar-forma-pk.png)

![Добавленный товар на сайте, компьютер](screenshots/37-noviy-tovar-pk.png)

![Новая категория, компьютер](screenshots/38-admin-kategoriya-pk.png)

Импорт из Excel (CSV): строки с ошибками пропускаются, в отчёте — номер строки и что исправить.

![Импорт товаров, компьютер](screenshots/39-import-tovarov-pk.png)
