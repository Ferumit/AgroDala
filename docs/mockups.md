# Макеты страниц

Вместо макетов в Figma — скриншоты свёрстанных страниц с тестовыми данными из базы. Снимает их
`npm run screenshots` в Chromium: компьютер — окно 1366×900, планшет — 768×1024, телефон — 390×844 и
360×640 (эмуляция Pixel 7).

Вход, регистрация и личный кабинет работают. Корзина и админ-панель показывают данные из базы, а их
кнопки пока неактивны: логика — 5-я неделя по ТЗ. Фото товаров взяты с Wikimedia Commons, авторы
перечислены в [image-credits.md](image-credits.md).

## Главная страница

Иконки категорий вверху страницы, под ними раскрывающийся блок фильтров и сортировки, ниже —
карточки товаров из базы.

![Главная страница, компьютер](screenshots/01-glavnaya-pk.png)

Блок фильтров раскрыт: назначение, тип, страна, ценовой диапазон или своя цена «от — до»,
производитель, наличие, сортировка.

![Фильтры и сортировка, компьютер](screenshots/02-filtry-pk.png)

Категория «Полив и опрыскивание» — открывается одним нажатием на иконку.

![Категория, компьютер](screenshots/03-kategoriya-pk.png)

На телефоне иконки категорий прокручиваются по горизонтали, товары идут в две колонки, на планшете —
в три.
