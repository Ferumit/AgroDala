# AgroDala

Интернет-магазин сельскохозяйственного инструмента: категории по назначению с иконками на главной
странице, раскрывающийся блок фильтров и сортировки, градация цен, личный кабинет, корзина и
административная панель. Все товары, покупатели и заказы хранятся в Cloud Firestore.

Учебный проект по дисциплине «Алгоритмы и структуры данных» (КАТИУ им. С. Сейфуллина,
группа КИ СОПР 25-22). Автор — Титов Е. И.

## Технологии

| Часть | Что используется |
|---|---|
| Клиент | HTML5, CSS3, JavaScript (ES-модули) без фреймворков и сборщика |
| База данных | Cloud Firestore |
| Вход и регистрация | Firebase Authentication |
| Фотографии товаров | Cloud Storage for Firebase |
| Серверные операции | Cloud Functions на Node.js 22 (расчёт суммы заказа, статусы, импорт CSV) |
| Разработка и тесты | Firebase Local Emulator Suite, Vitest, `@firebase/rules-unit-testing` |
| Хостинг | статические файлы из `public/` (по ТЗ — PS.kz) |

Сайт работает без собственного сервера: браузер напрямую обращается к Firebase, а всё, что нельзя
доверять браузеру, проверяют правила безопасности и Cloud Functions.

## Запуск на своём компьютере

Нужны **Node.js 22+** и **Java 21+** (на Java работают эмуляторы Firebase). Аккаунт Google и
настоящий проект Firebase не нужны: всё работает в локальных эмуляторах с проектом
`demo-agrodala`.

```sh
npm install        # один раз
npm run dev        # эмуляторы: сайт, база, вход, хранилище
npm run seed       # в другом терминале: заполнить базу тестовыми данными
```

- сайт — http://127.0.0.1:5000
- панель эмуляторов (данные базы, пользователи) — http://127.0.0.1:4000

После перезапуска `npm run dev` база пустая: снова выполните `npm run seed`.

Тестовые учётные записи (пароль у всех `agrodala123`):

| Почта | Роль |
|---|---|
| `admin@agrodala.example` | администратор |
| `manager@agrodala.example` | менеджер по продажам |
| `content@agrodala.example` | контент-менеджер |
| `buyer@agrodala.example` | покупатель |

Проверка правил безопасности (сначала остановите `npm run dev`, тесты поднимают свой эмулятор):

```sh
npm test
```

## Структура

```
public/                 сайт: всё, что загружается в браузер
  index.html            главная: иконки категорий, фильтры, каталог
  product.html          карточка товара
  cart.html             корзина и оформление заказа
  login.html            вход, регистрация, восстановление пароля
  account.html          личный кабинет
  admin.html            административная панель
  css/style.css         стили (mobile-first, от 360 px)
  js/firebase.js        подключение к Firebase и эмуляторам
  js/layout.js          общие шапка и подвал
  js/auth.js            общее для входа и кабинета: профиль, ошибки входа
  js/dictionaries.js    справочники: назначения, типы, ценовые диапазоны, статусы
  img/icons/            иконки Lucide (лицензия ISC)
seed/                   тестовые категории, поставщики и товары (JSON)
seed/images/            фото товаров и сведения об их авторах
scripts/seed.js         заполнение эмулятора тестовыми данными
firestore.rules         правила доступа к базе
storage.rules           правила доступа к фотографиям
tests/                  тесты правил безопасности
docs/database.md        структура базы данных
docs/mockups.md         макеты: скриншоты страниц на компьютере и телефоне
```

## Примечания
